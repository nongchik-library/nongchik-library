# Nongchik Library V136

ต่อยอดจาก V135 โดยเพิ่มข้อมูลเฉพาะเมนู **ศกร.ระดับตำบล**

- ข้อมูลอาคารสถานที่
- เวลาเปิดทำการ
- สิ่งอำนวยความสะดวก
- ครุภัณฑ์
- แสดงชื่อพื้นที่เป็น “ศกร.ระดับตำบลเกาะเปาะ” ในเมนู ศกร.
- แสดงข้อมูลใหม่ใน Detail
- รองรับข้อมูลใหม่ใน PDF/Word

หมายเหตุ: ฐานข้อมูลยังเก็บค่า `subdistrict` เป็นชื่อเดิม เช่น `เกาะเปาะ` เพื่อไม่กระทบ RLS, Google Drive และข้อมูลเดิม
