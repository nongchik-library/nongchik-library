# V23 – แก้ Dashboard และเพิ่มโครงการศูนย์ฝึกพัฒนาอาชีพ

- แก้พื้นที่กราฟสัดส่วนข้อมูล (Donut chart) ที่เกิด Bottom overflow ด้วยการเพิ่มความสูงพื้นที่แสดงผลและลดระยะห่างรายการคำอธิบาย
- เพิ่มการ์ด “โครงการศูนย์ฝึกพัฒนาอาชีพ” ในหน้า Dashboard
- แสดงจำนวนโครงการจากตาราง community_career_projects และกดการ์ดเพื่อเปิดหน้าจัดการโครงการเดิมได้
- เพิ่มจำนวนโครงการในคำอธิบายความก้าวหน้ารวม
- ไม่เปลี่ยนโครงสร้างตารางหรือข้อมูลเดิม
