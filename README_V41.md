# Nongchik Library v41

แก้ปุ่ม "เปิดดู" ในคลังรูปภาพและเอกสาร

- JPG/JPEG/PNG/WEBP: เปิดดูในแท็บใหม่แบบแสดงภาพ ไม่ดาวน์โหลด
- PDF: เปิดดูใน Chrome แบบแสดงเอกสาร ไม่ดาวน์โหลด
- DOC/DOCX: เปิดผ่าน Microsoft Office Online Viewer
- ปุ่มดาวน์โหลดเดิมยังคงดาวน์โหลดไฟล์ตามปกติ
- ใช้ signed URL และ blob สำหรับไฟล์ที่ Chrome มักตีความเป็น attachment
