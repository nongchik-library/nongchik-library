# Nongchik Library App V137

V137 ต่อจาก V136 ที่ผ่านการทดสอบการบันทึก Supabase และ Google Drive แล้ว

## การปรับปรุง
- เมนู 1-4, 6-7 เพิ่ม: เพศ, วัน เดือน ปี เกิด, จบการศึกษาระดับ, อาชีพปัจจุบัน, ครูผู้รับผิดชอบ, ตำแหน่ง, เบอร์โทรติดต่อ
- เมนู 1-4, 6-7 เพิ่ม: กระบวนการเรียนรู้
- ทุกเมนู รวมเมนู 5 ศกร.ระดับตำบล เพิ่ม/รองรับ: ข้อมูลอาคารสถานที่, เวลาเปิดทำการ, สิ่งอำนวยความสะดวก, ครุภัณฑ์
- ปรับไอคอนและหัวข้อ Card ให้สวยงามและสม่ำเสมอขึ้น
- รักษาระบบ Google Drive, GPS, รูปภาพ, เกียรติบัตร, PDF/Word และระบบ Login เดิม

## Supabase
รันไฟล์ `supabase_v137_add_fields.sql` ใน Supabase SQL Editor แล้วตรวจสอบผลก่อนทดสอบบันทึกข้อมูล

## หมายเหตุ
เมนู 5 ไม่แสดงข้อมูลบุคคล/กระบวนการเรียนรู้ตามข้อกำหนด แต่ยังคงข้อมูลตำแหน่งและเบอร์โทรศัพท์เดิม และมีข้อมูลอาคาร/เวลา/สิ่งอำนวยความสะดวก/ครุภัณฑ์
