# V131 – ปรับ PDF/Word ไม่ให้ล้นหน้ากระดาษ

ฐาน: V130 ที่ผู้ใช้ทดสอบว่าสำเร็จ

ปรับเฉพาะการจัดหน้ารายงาน PDF และ Word:
- เปลี่ยนหน้ารายงานจากความสูงคงที่/ซ่อนเนื้อหา เป็นการไหลตามเนื้อหา (natural pagination)
- footer ไม่ใช้ position:absolute จึงไม่ทับตารางหรือข้อมูล
- ลดขนาดภาพประกอบและภาพเกียรติบัตรให้เหมาะกับ A4
- ป้องกันแถวข้อมูล/การ์ดบุคคล/การ์ดเกียรติบัตรถูกตัดกลางส่วนเมื่อพิมพ์
- คงชื่อ-นามสกุล รูปบุคคล ภาพเกียรติบัตร และระบบ Google Drive เดิมทั้งหมด
- ไม่แก้ฐานข้อมูลและไม่แก้ระบบอัปโหลด

ทดสอบโดยรันโปรเจกต์แล้วเปิดข้อมูลที่มีข้อความยาว รูปบุคคล และเกียรติบัตร จากนั้นกด PDF และ Word
