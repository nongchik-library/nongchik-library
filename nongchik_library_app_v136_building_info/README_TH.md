# ห้องสมุดประชาชนอำเภอหนองจิก — V5

รุ่นนี้รวมระบบข้อมูล 7 หมวด พร้อมรูปภาพหลายรูป, GPS, สถานะรอตรวจสอบ และศูนย์ตรวจสอบสำหรับ Admin

## เมนูข้อมูล
1. แหล่งเรียนรู้
2. ภูมิปัญญาท้องถิ่น
3. ปราชญ์ชาวบ้าน
4. บ้านหนังสือชุมชน
5. ศกร.ระดับตำบล
6. แหล่งท่องเที่ยวในตำบล
7. อาหาร/ขนมโบราณในชุมชน

## การใช้งาน
- ครูเพิ่ม/แก้ไขข้อมูลของตนเองได้
- เพิ่มรูปภาพได้หลายรูป
- จับพิกัด GPS ได้จากเครื่อง
- เมื่อบันทึก ข้อมูลจะเป็น “รอตรวจสอบ”
- Admin อนุมัติ/ไม่อนุมัติได้
- ผู้ใช้ทั่วไป/ครูไม่สามารถลบข้อมูลของผู้อื่นได้
- การลบข้อมูลทำได้โดย Admin เท่านั้น

## V11 – แผนที่แหล่งเรียนรู้
- เพิ่มหน้า “แผนที่แหล่งเรียนรู้” ในหน้าแรก
- รวมข้อมูลที่อนุมัติแล้วจากทั้ง 7 หมวดที่มีพิกัด GPS
- ค้นหาชื่อ/รายละเอียด และกรองตามหมวด/ตำบล
- แตะหมุดเพื่อดูข้อมูลและเข้าสู่หน้ารายละเอียด
- ใช้แผนที่ OpenStreetMap


## V12 – จัดการผู้ใช้งานและสิทธิ์
- เพิ่มหน้า Admin: จัดการผู้ใช้งานและสิทธิ์
- กำหนดบทบาท Teacher / Admin
- กำหนดตำบลที่ครูรับผิดชอบจากบัญชีผู้ใช้
- เปิด/ปิดการใช้งานบัญชีผ่าน `profiles.is_active`
- ครูไม่สามารถเปลี่ยน role หรือ assignment ของตนเอง
- ครูเพิ่ม/แก้ไขข้อมูลได้เฉพาะตำบลที่ได้รับมอบหมาย
- การลบข้อมูลทำได้เฉพาะ Admin
- การสร้าง/ลบรหัสผ่านบัญชีทำผ่าน Supabase Authentication; หน้า V12 จัดการเฉพาะสิทธิ์และข้อมูลโปรไฟล์

ก่อนใช้งาน V12 ให้รัน `supabase_schema_v12.sql` ใน Supabase SQL Editor 1 ครั้ง
