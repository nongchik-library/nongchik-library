# Nongchik Library v33

เพิ่มข้อมูลย่อยสำหรับข้อมูลทุกหมวดหลัก:
- ประวัติความเป็นมา
- ประวัติของแหล่งเรียนรู้
- รางวัลที่ได้รับ (กรอกข้อความได้)
- เกียรติบัตร / หลักฐานรางวัล (อัปโหลด PDF, JPG, PNG, DOC, DOCX ได้หลายไฟล์)

ต้องรัน `supabase_schema_v33.sql` ใน Supabase SQL Editor ก่อนใช้งานข้อมูลใหม่
