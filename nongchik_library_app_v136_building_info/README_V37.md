# Nongchik Library v37

แก้หน้า “คลังรูปภาพและเอกสาร” ไม่ให้หน้าว่างเมื่อ Supabase/โฟลเดอร์มีปัญหา

## สิ่งที่เพิ่ม
- หน้าแสดงผลทันที ไม่รอข้อมูลจนหน้าว่าง
- โหลดไฟล์และโฟลเดอร์แยกกัน
- มี timeout และแสดงสาเหตุผิดพลาด
- ปุ่มอัปโหลดในหน้า + FAB
- สร้างโฟลเดอร์พร้อมรายละเอียด
- อัปโหลดพร้อมเลือก/สร้างโฟลเดอร์
- ชื่อไฟล์และรายละเอียด
- ค้นหา/กรอง/ดาวน์โหลด
