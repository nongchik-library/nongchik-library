# V125 — แยก Google Drive ตามตำบล

ฐานจาก V124 `nongchik_library_app_v124_save_category_fix.zip` ที่ทดสอบแล้วว่าบันทึกข้อมูลและอัปโหลดรูปเข้า Google Drive ได้

## สิ่งที่เปลี่ยน
- ทุกเมนูข้อมูลหลัก 7 เมนูยังใช้ระบบเดิม
- ไฟล์จาก DataForm จะเก็บใน Google Drive ตามโครงสร้าง:
  - `<ตำบล>/ภาพแหล่งเรียนรู้`
  - `<ตำบล>/เกียรติบัตรและหลักฐาน`
- ระบบสร้างโฟลเดอร์อัตโนมัติเมื่อยังไม่มี
- ส่ง `subdistrict` ไปพร้อม metadata ของไฟล์
- ไม่เปลี่ยนค่า `category` ของ V124
- ไม่แก้ Detail / รูป 5 รูป / Scroll / ระบบบันทึกข้อมูล

## เมนูที่ครอบคลุม
1. แหล่งเรียนรู้
2. ภูมิปัญญาท้องถิ่น
3. ปราชญ์ชาวบ้าน
4. บ้านหนังสือชุมชน
5. ศกร.ระดับตำบล
6. แหล่งท่องเที่ยวในตำบล
7. อาหาร/ขนมโบราณในชุมชน

## ทดสอบ
แนะนำให้ทดสอบ 1 ตำบลก่อน โดยเพิ่มข้อมูลใหม่ + รูปใหม่ 1 รูป แล้วตรวจ Google Drive ว่าเกิด `<ตำบล>/ภาพแหล่งเรียนรู้` และรูปอยู่ในนั้นจริง
