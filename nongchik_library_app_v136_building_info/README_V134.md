# V134 — ปรับชื่อหน่วยงานอย่างเป็นทางการ

ปรับชื่อ/หัวเอกสารเป็น:

1. งานการศึกษาตลอดชีวิต
2. ห้องสมุดประชาชนอำเภอหนองจิก
3. ศูนย์ส่งเสริมการเรียนรู้ระดับอำเภอหนองจิก
4. สำนักงานส่งเสริมการเรียนรู้ประจำจังหวัดปัตตานี
