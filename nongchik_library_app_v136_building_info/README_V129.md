# V129 — ปรับหน้ารายละเอียดให้สวยงามและเป็นระเบียบ

ฐานจาก V128 ที่ทดสอบแล้วว่า 7 เมนูบันทึกข้อมูลและอัปโหลด Google Drive ได้สำเร็จ

## ปรับปรุง
- ปรับหน้า Detail ให้เป็นระเบียบ มีส่วนหัวข้อมูลและหมวดข้อมูลชัดเจน
- แสดงชื่อ–นามสกุลและรูปบุคคลใน Card แบบเด่นชัด
- แสดงรูปประกอบสูงสุด 5 รูป พร้อมภาพหลักและภาพย่อย
- กดรูปเพื่อดูเต็มจอได้
- จัดข้อมูลรายละเอียด / GPS / สถานะ / รหัสข้อมูลเป็นหมวด
- จำกัดความกว้างเนื้อหาเพื่อให้เหมาะกับจอใหญ่ และยังรองรับจอเล็ก
- ไม่เปลี่ยนระบบบันทึกข้อมูล, Google Drive, Edge Function หรือโครงสร้างฐานข้อมูลของ V128

## สำคัญ
V129 เป็นการปรับ UI หน้า Detail เท่านั้น ไม่ต้องรัน SQL เพิ่ม หากฐานข้อมูลของ V128 ถูกตั้งค่าเรียบร้อยแล้ว
