# V132 – เพิ่มช่องตำแหน่งผู้รับผิดชอบ

ฐานพัฒนาจาก V131 ซึ่งผู้ใช้ยืนยันว่า PDF/Word สวยงามและไม่ล้นหน้ากระดาษ

## เพิ่ม
- เพิ่มช่อง `ตำแหน่ง` ในเมนูเพิ่มข้อมูลทั้ง 7 เมนู
- โหลดค่า `position` เมื่อแก้ไขข้อมูลเดิม
- บันทึก `position` ลง Supabase
- แสดงตำแหน่งใต้ชื่อบุคคลในส่วนบุคคลผู้ให้ข้อมูลของ PDF/Word
- แสดง `ตำแหน่ง` ในตารางรายละเอียดของ PDF/Word
- แสดง `ตำแหน่ง` ในหน้า Detail ของแอป

## สำคัญ
ต้องรัน `supabase_add_position_v132.sql` ใน Supabase SQL Editor **ครั้งเดียว** ก่อนทดสอบ V132

ไม่เปลี่ยนระบบ Google Drive, การแยกโฟลเดอร์ตามตำบล/เมนู, รูปบุคคล, รูปแหล่งเรียนรู้ หรือรูปเกียรติบัตร
