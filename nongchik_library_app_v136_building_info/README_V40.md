# Nong Chik Library v40

แก้ระบบคลังรูปภาพและเอกสารจาก v39

- แก้ InvalidKey ของ Supabase Storage ที่เกิดจากการใช้ชื่อโฟลเดอร์ภาษาไทยเป็น Storage object key
- Storage ใช้ UUID ของโฟลเดอร์แทนชื่อโฟลเดอร์ แต่หน้าจอยังคงแสดงชื่อภาษาไทยตามเดิม
- อัปโหลดแบบ “สร้างโฟลเดอร์ใหม่พร้อมอัปโหลด” ได้
- ถ้าเลือกโฟลเดอร์เดิม ระบบใช้โฟลเดอร์เดิม ไม่สร้างซ้ำ
- เพิ่มปุ่ม “เปิดดู” ด้วย signed URL
- ปรับดาวน์โหลดบน Chrome ให้ดาวน์โหลดผ่าน Blob เพื่อหลีกเลี่ยงปัญหา cross-origin download
- ไม่ต้องเปลี่ยนโครงสร้างตาราง Supabase จาก v38 สำหรับการแก้ครั้งนี้
