# V127 — เพิ่มช่องชื่อและนามสกุลครบทั้ง 7 เมนู

ฐาน: V126 ที่ทดสอบ Google Drive แยกตามตำบลสำเร็จ

## เพิ่ม
- ช่อง ชื่อ และ นามสกุล ในเมนูเพิ่มข้อมูลทั้งหมด 7 เมนู
- โหลดค่ากลับเมื่อแก้ไขข้อมูล
- บันทึกลง first_name และ last_name

## ไม่เปลี่ยน
- Google Drive: ตำบล/ภาพแหล่งเรียนรู้ และ ตำบล/ภาพเกียรติบัตร
- Edge Function drive-upload
- ระบบรูปภาพ 5 รูป / Detail / Scroll
